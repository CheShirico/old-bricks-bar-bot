# The Old Bricks Bar — Telegram-бот

Telegram-бот бара The Old Bricks Bar (Алматы). Отвечает гостям про меню, цены, график работы и адрес, а также принимает заявки на бронь стола. Ответы генерирует бесплатная модель через [OpenRouter](https://openrouter.ai), заявки уходят администратору в Telegram и строкой в Google Таблицу.

Проект без внешних зависимостей: только Node.js 20.12+ и встроенный `fetch`.

## Возможности

- **Вопросы и ответы.** Бот знает меню кухни и бара, цены, график работы, адрес и телефон. Данные лежат в [`knowledge.md`](knowledge.md) и подставляются в системный промпт. Чего в базе нет, того бот не выдумывает и отправляет гостя звонить.
- **Открыто ли сейчас.** Это считает код ([`schedule.js`](schedule.js)) по времени Алматы с учётом субботы до 02:00, а не модель.
- **Заявки на бронь.** Диалог `/book` или «хочу забронировать»: дата, время, число гостей, имя, телефон, пожелания, подтверждение ([`booking.js`](booking.js)). Не принимает заявки на выходные дни (пн–ср), на время до открытия и на прошедшие даты.
- **Два канала заявок.** Сообщение администратору в Telegram и строка в Google Таблице. Заявка считается принятой, если дошла хотя бы по одному каналу.
- **Запасные модели.** Если основная бесплатная модель отвечает 429 или 5xx, бот пробует следующую.
- **Память диалога.** Последние 20 сообщений на чат; `/reset` очищает.

## Команды бота

| Команда | Что делает |
|---|---|
| `/start` | Приветствие |
| `/book` | Оформить заявку на бронь стола |
| `/reset` | Очистить контекст диалога и незавершённую заявку |
| `/id` | Показать ID чата (нужен, чтобы настроить `ADMIN_CHAT_IDS`) |

## Быстрый старт

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Получите ключ на [openrouter.ai](https://openrouter.ai/keys).
3. Скопируйте `.env.example` в `.env` и заполните значения (см. таблицу ниже).
4. Запустите:

```powershell
npm start
```

## Настройка `.env`

| Переменная | Назначение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | Токен бота от @BotFather |
| `OPENROUTER_API_KEY` | Ключ OpenRouter |
| `OPENROUTER_MODEL` | Основная модель, например `nvidia/nemotron-3-ultra-550b-a55b:free` |
| `OPENROUTER_FALLBACK_MODELS` | Запасные модели через запятую (необязательно) |
| `ADMIN_CHAT_IDS` | ID чата администратора или группы, куда приходят заявки (несколько через запятую) |
| `SHEET_WEBHOOK_URL` | Адрес развёрнутого Google Apps Script (необязательно) |
| `SHEET_SECRET` | Общий секрет бота и скрипта |

Чтобы узнать `ADMIN_CHAT_IDS`, напишите боту `/id` из нужного чата (для группы добавьте туда бота).

Файл `.env` содержит секреты и не попадает в репозиторий.

## Заявки в Google Таблицу

1. Создайте Google Таблицу, откройте «Расширения → Apps Script» и вставьте код из [`apps-script.example.gs`](apps-script.example.gs).
2. Замените `__SECRET__` на длинную случайную строку и пропишите ту же строку в `SHEET_SECRET` в `.env`.
3. «Развернуть → Новое развёртывание → Веб-приложение»: запуск «От моего имени», доступ «Все». Разрешите скрипту доступ к таблице.
4. Скопируйте адрес вида `https://script.google.com/macros/s/.../exec` в `SHEET_WEBHOOK_URL`.

Запросы без правильного секрета скрипт отклоняет. Скрипт сам создаёт лист «Заявки» с шапкой и добавляет заявки строками со статусом «Новая».

## Как обновить меню и график

- **Меню, цены, контакты.** Правьте [`knowledge.md`](knowledge.md). Файл читается при каждом сообщении, перезапуск не нужен.
- **График работы.** Правьте `HOURS` в [`schedule.js`](schedule.js) (и раздел про график в `knowledge.md`), затем перезапустите бота.

## Структура

```
bot.js                    Telegram long polling, OpenRouter, отправка заявок
booking.js                диалог брони: разбор дат, времени, телефона, шаги
schedule.js               график работы, «открыто ли сейчас»
knowledge.md              база знаний: меню, цены, адрес
apps-script.example.gs    скрипт для записи заявок в Google Таблицу
.env.example              шаблон переменных окружения
```

## Замечания

- Бесплатные модели OpenRouter имеют лимиты и время от времени отвечают 429. Для этого и нужны запасные модели.
- Бот не гарантирует бронь: её подтверждает администратор по телефону.
- Бот работает, пока запущен процесс. Для постоянной работы разместите его на сервере и запускайте через менеджер процессов (например, pm2).
